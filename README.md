# IC2 Classic Port Prototype

Прототип переноса IC2 Classic 2.1.3.3 с Forge 1.19.2 на **Minecraft 1.21.1 и NeoForge**. В проекте используется Java 21.

## Локальная сборка

Оригинальные текстуры берутся из локальной копии IC2 Classic 1.19.2-2.1.3.3. Выполни эти команды в PowerShell из корня проекта.

~~~powershell
.\scripts\Import-OriginalTextures.ps1 -OriginalJar 'C:\path\to\ic2classic-1.19.2-2.1.3.3.jar'
.\gradlew.bat build
~~~

Клиент разработки запускается через **gradlew.bat runClient**. На этой машине прототип 0.10.0 был собран через JDK с подготовленными зависимостями NeoForge, а штатная сборка Gradle упиралась в загрузку файлов Minecraft.

## Состояние 0.10.0

В прототипе доступны топливный генератор, медный кабель, BatBox, аккумулятор, дробитель, электропечь, экстрактор, компрессор и базовая солнечная панель. Механизмы находятся во вкладке редстоуна. В тестовых мирах на NeoForge 21.1.234 проверены передача EU, загрузка через воронки, перенос заряда аккумулятором и остановка солнечной выработки ночью, в дождь и под крышей.

Крафт большинства блоков, полные списки рецептов машин, продвинутые уровни сети и совместимость с сохранениями оригинала требуют дальнейшего переноса.
