# IC 2 Classic Re 0.71.1 — тестовая сборка

Minecraft **1.21.1**, **Java 21**, **NeoForge 21.1.219 или новее в серии 21.1**. Клиентские проверки выполнялись на NeoForge 21.1.238. Для одинакового окружения у тестеров рекомендуется 21.1.238.

## Установка

1. Установить Minecraft 1.21.1 с NeoForge.
2. Положить `ic2-classic-re-0.71.1.jar` в папку `mods`, убрав предыдущий JAR этого мода.
3. Для первых проверок использовать отдельный мир или копию существующего.

JEI необязателен. При проверке на выделенном сервере поставить эту же версию мода на сервер и клиент.

## Что изменилось

- Объединены новые интерфейсы механизмов из ветки gui-only.
- Обновлены оставшиеся окна колоссальных машин, конфигуратора брони, хранилищ, ящиков инструментов, пищевого модуля и ядерного джетпака.
- Подключены отсутствовавшие экраны шахтёра, разогнанного насоса, насоса дальнего действия и электрического зачарователя.
- Восстановлены недостающие модели предметов и названия EN/RU.

## Что проверить

- Открытие окон, читаемость текста, разные масштабы GUI и русский/английский язык.
- Перемещение предметов, Shift-клик, сохранение содержимого после выхода и входа.
- Вкладки рецептов, загрузку ингредиентов, кнопки и показания энергии.
- Реальную работу механизмов с энергией и ресурсами, а не только открытие окна.
- Одиночную игру и, если есть возможность, отдельный сервер.

Колоссальные механизмы требуют собранного мультиблока: одиночный контроллер не открывает GUI. Минимальная структура — куб 2×2×2 из контроллера и семи `ic2:colossal_base`; основание располагается за контроллером, справа относительно внутреннего направления структуры и вниз. Мод остаётся в разработке; эта сборка предназначена для сбора замечаний.

## Что присылать при ошибке

```text
Версия мода: 0.71.1
Версия NeoForge:
Другие моды:
Одиночная игра / сервер:
Название или ID предмета/механизма:
Шаги воспроизведения:
Ожидалось:
Получилось:
```

Приложить скриншот или видео, `logs/latest.log`; при падении — соответствующий файл из `crash-reports`. Для графических ошибок указать язык и масштаб GUI.

## Проверки сборки

Offline Gradle build и серверный API smoke suite для версии 0.71.1 прошли. Версия внутри JAR проверена; тестовые классы exampleaddon в него не включены. Предыдущий клиентский прогон проверил открытие десяти обновлённых меню; это не означает полного тестирования всех механик и совместимости с другими модами.
