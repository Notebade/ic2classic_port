# Ядерная ветка и генерация — 0.70.0

Этап завершает функции прежних пунктов 1–2 в `осталось.md`. Minecraft 1.21.1, NeoForge 21.1.219, Java 21; источником служит локальный IC2 Classic 1.19.2-2.1.3.3.

## Реализованные функции

| Подсистема | Результат |
|---|---|
| Монитор | Прямоугольные стены из панелей одной ориентации, общий расход EU `max(width,height)`, питание через любую панель, карты всех панелей, фиксация группы, 16 цветов, масштаб 1–10 и выравнивание слева/по центру/справа. Настройки сохраняются и синхронизируются. |
| Ядерные расчёты | Сохранены электрический/паровой режимы, камеры, компоненты и полный прогон планировщика. Проверены 18 сочетаний шести топлив и трёх размеров стержня: исходные выработка, нагрев и износ первого цикла. Есть остановка по топливу/перегреву, общая продукция, ресурс и КПД. |
| Перегрев | Исходные угловые лучи взрыва, поглощение сопротивлением, вторичные лучи, защита бедроком/иридиевым камнем, внешняя зона редких выпадений, урон/отбрасывание, голод и радиация. Нагрев плавит подходящие окружающие блоки. |
| Настройки | `ic2-server.toml`: nuclearGeneratorMultiplier, steamReactorMultiplier, reactorDamage, solarTurbineMultiplier, slagGenBase, windmillOutput, steamTunnelBase, steamTurbineBase, fluidGeneratorMultiplier. Значения по умолчанию соответствуют оригиналу. Нулевой reactorDamage отключает разрушительные эффекты реактора. |
| Термояд | Исходный cobblegen_upgrade пополняет материал без расходования предмета; обычный булыжник и незерак сохраняют свои режимы. Есть оба исходных варианта крафта улучшения с водой и магмой/лавой. |
| Рецепты баков | Машинный бак — стекло вокруг машинного буфера; личный — вокруг личного сундука. Зависимости работают: буфер на 9 слотов/500 EU/LV, сундук на 54 слота с владельцем, базовый ящик на 8 рабочих слотов. Заполненный ящик нельзя потерять при крафте буфера. |
| Оформление | Исходные фоны и координаты слотов солнечной турбины, шлакового/жидкотопливного генераторов, мельницы, плазмафайера, котла и термояда. У монитора — исходная основа и новые элементы управления. У планировщика видны границы каждого слота. Подробные значения генераторов доступны подсказками. |
| Звук | Основной цикл реактора и три исходных уровня Гейгера; переключение по синхронизированной выработке. Сохранены звуки мельницы, шлакового и жидкотопливного генераторов. Нет цикла при нулевой выработке реактора. |
| Паровой тоннель | Исходная анимированная накладка турбины и частицы; диск 3×3 появляется только у собранной структуры. Отдельный контроллер и предмет не рисуют большой диск. |
| Жизненный цикл структур | Сохранение, границы чанков, исключительное владение клапаном, повторная сборка и отказ старых обработчиков после разборки/выгрузки. Изменение LIT/FORMED не запускает обновление соседних форм и не подгружает отсутствующие чанки. |

## Проверка

`gradlew.bat check --offline --console=plain -q`: **20 автономных наборов** и компиляция отдельного примера аддона. Новые наборы проверяют геометрию/выравнивание монитора, регулируемую выработку и исходные формулы ядерного взрыва.

`scripts/Test-AddonApi.ps1`: выделенный сервер в изолированном мире. Дополнительно проверены стена 2×2, общий расход энергии и сохранение оформления, неполная стена, 18 вариантов топлива, исходные рецепты зависимостей, содержимое ящика, запрет вложения ящика в себя/использования девятого слота, права чужого игрока, бесконечный булыжник, конкурирующие контроллеры, настоящий взрыв и отсутствие загрузки соседнего чанка взрывом. Проверка выгрузки выполняется между настоящими серверными тиками: удерживается только чанк контроллера, соседний чанк выгружается и затем загружается, жидкость сохраняется.

Клиентская проверка: **15 настоящих экранов с JEI и стена мониторов**. Снимки получены из кадра Minecraft, затем визуально просмотрены; исправлены границы слотов планировщика и масштаб текста стены. Использован установленный NeoForge **21.1.238**, поскольку локальный JEI 19.64.0.455 требует эту версию. Основной мод продолжает компилироваться и проходить серверные проверки на 21.1.219; JEI необязателен.

Повтор клиентского прогона из корня проекта:

```powershell
./scripts/Test-GenerationClient.ps1 -OriginalJar <путь-к-оригинальному-JAR> -WorldPath <путь-к-тестовому-миру> -JeiJar <путь-к-JEI>
```

Скрипт копирует мир в `runs/generation-client-check`, собирает временный аддон, запускает клиент с `ic2.client.verify`, сохраняет снимки, завершает клиент и удаляет тестовый аддон. Исходный мир не изменяется. `exampleaddon`/`client-checks` **не нужны для игры** и не включаются в основной JAR. PNG/OGG оригинала импортируются локально и исключены из Git.

## Границы общих подсистем

Монитор объединяет прямоугольники до 256 загруженных панелей; неполные фигуры работают одиночными панелями. Группу можно зафиксировать перед установкой соседних экранов. Масштаб использует исходные единицы `scale/256`; настройки доступны на каждой панели. В отличие от исходной централизованной сетки, карты остаются в своих панелях и не теряются при разделении стены.

Взрыв обрывает луч на выгруженном чанке. Публичный реестр расширения ExplosionWhitelist, достижения и прочие внешние программные реестры относятся к общему API/интеграциям. Базовая ветровая модель перенесена; направленная RealisticWindCalculation не была стандартным режимом оригинала.

Полный FluidNet остаётся в пункте 10; общие устанавливаемые улучшения — в пункте 7. Исходные генераторы этого этапа не получают произвольные машинные улучшения: специальное бесконечное топливо термояда перенесено отдельно. Оригинальное крепление/остекление светильников относится к строительству, расширенные функции буфера/личного сундука и ящика — к хранению/инструментам. У этих зависимостей пока адаптированы GUI; у ящика ещё нет исходной фильтрации, прокрутки и диагностических функций. Полные жидкостные слои/очереди и сохранение жидкости в демонтированном баке остаются работой по бакам. Заправка канистр котла через исходный консервировщик относится к химической ветке. Дальнейшая регрессия с другими модами и несколькими реальными сетевыми клиентами остаётся в общей проверке, пункт 12.

## Журнал действий

1. Сверены локальные исходники монитора, генераторов, термояда, контейнеров, рецептов и IC2Explosion; отсутствующие функции отделены от общих подсистем.
2. Добавлены падающие проверки отсутствующей геометрии, регулируемых расчётов и формул взрыва; реализованы функции и пройдены автономные проверки.
3. Восстановлены режимы монитора, конфигурация выработки, бесконечное топливо, исходные ресурсы GUI/звука/анимации и рабочие зависимости рецептов баков.
4. Расширены реальные серверные сценарии. Устранена загрузка соседнего чанка косметическим изменением состояния; старые обработчики проверяют принадлежность живому экземпляру блока.
5. Выполнены клиентские прогоны с JEI и визуальная проверка снимков. Обнаруженный диск на несобранном тоннеле ограничен состоянием FORMED.
6. После несовместимого локального форматтера точечно восстановлены конструкции Java 21; выполнены повторные компиляция и поведенческие проверки. Инструменты crapper/dryer/mutator в сессии недоступны; отдельные результаты этих инструментов не заявляются.
7. Обновлены версия, API/README, журнал и список остатка. Результат предназначен для локального коммита; push не выполняется.
